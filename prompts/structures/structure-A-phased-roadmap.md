# Structure A — Phased Execution Roadmap

Extracted from "The 90-Day Execution Roadmap — From Zero to 10 Calls/Day".

**Use when:** the reader needs to _do_ something over time and the value is knowing
the order and the pace. Transformation over a period.

**Title formula:** `The [N-period] [Noun] — From [Bad State] to [Quantified Good State]`
The title must contain a number and a specific outcome. Never a vague promise.

---

## Page 1 — Cover

- Title
- One-line promise
- Client name and handle

## Page 2 — The Frame

A short block that does three jobs, in this order:

1. **Names the gap** — why knowing _what_ to do isn't enough
2. **States the promise** — where the reader ends up
3. **Gives one instruction** — e.g. "Follow it in order. Don't skip ahead."

_Reference: "Knowing what to do means nothing if you don't know WHEN to do it."_

## Pages 3–N — One page per phase (3–5 phases)

Each phase page contains:

- **Phase marker + name** — phases progress visually (🟢 → 🟡 → 🟠 → 🔴)
- **Goal** — one bold line. "Goal: Fix the basics. Get your profile, ICP, and first content ready."
- **Time-boxed blocks** — "Week 1: Profile + ICP", "Day 1-2: Profile Overhaul (2-3 hours)"
  - Every block carries a **time estimate in brackets**
- **Actions as arrows (→)**, never bullet dots
  - Each action is imperative and specific
  - Where a formula exists, embed it inline:
    `I help [audience] go from [pain] to [outcome] using [method]`
  - Name real tools where relevant
- **End-of-phase checklist** using ✅ — every item measurable
  - "✅ 20+ posts published", "✅ First 2-3 calls booked from LinkedIn"

## Final page — Investment + Payoff

- Time commitment per phase, as a summary
- A closing reframe about compounding
  _Reference: "Month 1 feels slow. Month 2 builds momentum. Month 3 is when the
  system starts printing pipeline. Don't quit in month 1."_

---

## Rules for the generator

- **Every action must be executable today.** If the reader can't act on it this
  afternoon, it's a concept, not an action — cut it.
- **Time estimates on everything.** They make the plan feel real and reduce dread.
- **Checkpoints must be countable.** "Profile improved" fails. "5 posts published" passes.
- **Word budget: one phase = one page.** Do not let a phase flow across pages.
- **Escalating difficulty.** Phase 1 is setup, the last phase is optimisation.
- Never use bullet dots. Arrows for actions, ticks for checkpoints.
